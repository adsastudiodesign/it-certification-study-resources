# IT Certification Study Resources

**Free study checklists, topic outlines, and quick-reference sheets for IT certification exams** — published by **Mastering Careers & Skills** ([careersskillsbooks.com](https://careersskillsbooks.com)).

Every file here is a complete, standalone study aid: print it, pin it, and work through it as you prepare. Each one is drawn from the structure of a complete A-to-Z teaching book in the Mastering Careers & Skills library, and each one names the book it came from at the bottom of the file.

## How to use these files

- **Study with them.** Work down a checklist and tick off each topic only when you can explain it out loud, from memory, without looking anything up. The topics you cannot explain are your study plan.
- **Revise with them.** The quick-reference sheets are built for the last week before a sitting — the tables and lists your eyes should pass over daily.
- **Go deeper with the free chapter.** Every book in the library can be sampled before anything else: the first chapter of each book is free to read at [careersskillsbooks.com](https://careersskillsbooks.com), and each resource below links straight to its own book's page.
