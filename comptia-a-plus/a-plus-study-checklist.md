# CompTIA A+ Study Checklist — Core 1 (220-1201) & Core 2 (220-1202)

A tick-off map of the whole A+ field. Work down each list; tick a topic only when you can explain it out loud, from memory, to someone who has never opened a computer case. Whatever you cannot explain is what you study next.

## Before anything else: the troubleshooting method

Every A+ scenario question is secretly asking whether you follow the method in order:

1. **Identify the problem** — gather information, question the user, check logs and recent changes.
2. **Establish a theory of probable cause** — question the obvious first; escalate if needed.
3. **Test the theory** — confirm the cause, or form a new theory.
4. **Establish a plan of action** — and identify its effects before you touch anything.
5. **Implement the solution or escalate** — one change at a time.
6. **Verify full system functionality** — and apply preventive measures.
7. **Document** — findings, actions, and outcomes.

## Core 1 — Mobile Devices

- [ ] Laptop hardware: batteries, SO-DIMM memory, HDD/SSD (2.5″, M.2, NVMe vs SATA), displays, webcams, microphones, wireless antennas
- [ ] Replacing laptop parts in the right order, and verifying the repair afterwards
- [ ] Accessories: docking stations vs port replicators, hubs, KVM switches
- [ ] Mobile connections: USB-C, Lightning, Bluetooth pairing, NFC, mobile hotspots
- [ ] MDM/MAM: what the management layer can enforce, enrol, and wipe
- [ ] Email and account setup on phones and tablets; synchronisation across devices

## Core 1 — Networking

- [ ] Protocols and ports: TCP vs UDP, and the common services (see the Network+ quick reference in this repo for the full ports table)
- [ ] SOHO routers and switches: setup, DHCP reservations, port forwarding, firmware
- [ ] Wireless standards and encryption: 802.11 generations, WPA2 vs WPA3, 2.4 GHz vs 5 GHz
- [ ] Internet connection types: cable, DSL, fibre, satellite, cellular
- [ ] Network cables and connectors: Cat 5e/6/6a, RJ45, punchdown blocks, crimping and testing

## Core 1 — Hardware

- [ ] Motherboards: form factors (ATX, microATX, ITX), sockets, expansion slots, headers
- [ ] RAM: DDR generations and why they are not interchangeable, channels, ECC
- [ ] Storage: HDD, SSD, RAID 0/1/5/10, optical and flash media
- [ ] CPUs: architectures, sockets, cooling — air, liquid, thermal paste, fan curves
- [ ] Power supplies: wattage, rails, modular vs fixed cabling, 20+4-pin ATX
- [ ] Printers: laser printing process in order (processing, charging, exposing, developing, transferring, fusing, cleaning), inkjet, thermal, impact, 3D; unjamming, calibration, maintenance kits
- [ ] Cables and connectors: HDMI, DisplayPort, USB generations and speeds, Thunderbolt

## Core 1 — Virtualization & Cloud

- [ ] Hypervisors: Type 1 (bare metal) vs Type 2 (hosted); resource requirements
- [ ] Cloud models: IaaS, PaaS, SaaS; public, private, hybrid, community
- [ ] Cloud characteristics: elasticity, scalability, metered services, file and application synchronisation
- [ ] Virtual desktops (VDI) and basic client-side virtualisation scenarios

## Core 1 — Hardware & Network Troubleshooting

- [ ] POST and beep codes; no-boot, no-video, and intermittent shutdown scenarios
- [ ] Storage faults: clicking drives, RAID rebuilds, boot errors, S.M.A.R.T. warnings
- [ ] Display faults: dead pixels, flicker, dim screens, projector problems
- [ ] Network faults: no connectivity, limited connectivity, slow speeds, IP conflicts
- [ ] Printer faults: paper jams, streaks, ghosting, faded output, queue stalls
- [ ] The toolkit: multimeter, cable tester, loopback plug, toner probe, crimper, Wi-Fi analyser

## Core 2 — Operating Systems

- [ ] Windows: editions and upgrade paths, Control Panel vs Settings, Task Manager, services, registry, command line (ipconfig, chkdsk, sfc, DISM, diskpart)
- [ ] macOS: Time Machine, Mission Control, Keychain, sharing and remote features
- [ ] Linux: package managers, permissions (chmod), core commands (ls, cd, grep, sudo, df, du)
- [ ] Installation methods: clean install, upgrade, image deployment, recovery partitions
- [ ] Filesystems: NTFS, FAT32, exFAT, APFS, ext4 — and which OS owns which
- [ ] Disk management: partitioning, formatting, drive letters and mount points

## Core 2 — Security

- [ ] Physical security: locks, badges, bollards, air gaps, Faraday cages
- [ ] Logical security: least privilege, MFA, ACLs, group policy, screen lock policies
- [ ] Wireless security: WPA3, enterprise vs personal authentication, disabling SSID broadcast (and why it is weak)
- [ ] Malware: viruses, worms, trojans, ransomware, keyloggers, rootkits — and the removal procedure in order
- [ ] Social engineering: phishing, spear phishing, vishing, whaling, pretexting
- [ ] Hardening: disabling unused services and ports, patch management, host firewalls, BitLocker and EFS

## Core 2 — Software Troubleshooting

- [ ] Windows faults: BSOD, boot loops, missing OS, application crashes, service failures
- [ ] Performance: slow disk, high CPU/memory, the tools that prove which one it is
- [ ] Mobile faults: battery drain, overheating, app crashes, connectivity loss
- [ ] Security symptoms: pop-ups, browser redirection, fake security alerts, certificate warnings

## Core 2 — Operational Procedures

- [ ] Safety: ESD straps and mats, air filters and masks, proper disposal of batteries and e-waste
- [ ] Change management: purpose, scope, risk, approvals, back-out plans, documentation
- [ ] Backup and recovery: full vs incremental vs differential, the 3-2-1 rule, testing restores
- [ ] Documentation: ticketing systems, asset tags, knowledge bases, acceptable use policies
- [ ] Professional conduct: communication, confidentiality, and respecting the user's data
